# Smart Support Desk - AI Enabled Ticket Management System

## Project Overview

Smart Support Desk is an AI-enabled ticket management system developed to simplify and automate customer support operations. The system allows users to create, track, update, and manage support tickets efficiently through a modern web interface and intelligent backend services.

The project integrates Artificial Intelligence for ticket classification, issue prioritization, automated suggestions, and email notifications to improve support efficiency and reduce manual workload.

# Workflow

1. User registers/login into the system
2. User creates a support ticket
3. AI analyzes the ticket
4. Ticket gets categorized and prioritized
5. Admin/support team reviews the issue
6. Comments and updates are added
7. Email notifications are sent
8. Ticket is resolved and closed

# Installation Steps

## Clone Repository

```bash
git clone https://github.com/priyagit-5k7/Smart-Support-Desk.git
```

## Frontend Setup

```bash
cd smart-support-ui
npm install
ng serve
```

## Backend Setup

```bash
cd SmartSupportDesk.API
dotnet restore
dotnet run
```
